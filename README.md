# Flex Driver Hub

A phone-friendly tracker for Amazon Flex drivers. Drivers type in each route; the app does the hours math, day/week/month totals, and a tax reserve, and exports everything to CSV.

- Not connected to Amazon. Every number comes from the driver.
- Routes are stored only on the driver's own phone.
- English and Spanish.

## Install on a phone
Open the site link, then:
- iPhone (Safari): Share → Add to Home Screen
- Android (Chrome): ⋮ menu → Install app
